# Space Trader Client
This purpose of this project is to create an interface that can communicate with the API-centric game [Space Traders](https://spacetraders.io/). Though I have experienced terminal-centric games before, one that enables the user to define what the interface looks like fascinates me a great deal. The possibilities for the types of projects that can utilize this API seem only limited by the creativity of a developer.

## Goal
The primary goal is to construct an interface that is capable of communicating with the game's API in every supported way. From there, introducing automation to tasks and combination of transactions to reduce the tedium of the operations the game provides. From there, introduce a UI that allows for workflows that support mouse-only input.

## Technologies
The project is based in Java, and uses Maven to manage dependencies to various projects (list below). A majority of the technologies are ones that I have prior professional experience with, though I hope to expand that repertoire with the eventual inclusion of other web technologies.
- Spring Framework (TomCat, Actuator)
- Gson
- Jackson
